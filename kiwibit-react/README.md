# Kiwibit Security Operations

An elite cybersecurity engineering collective landing page specializing in adversarial research and defensive product development for global sovereign enterprises.

## Technologies

- React 18
- Vite
- Tailwind CSS v4
- High-performance `requestAnimationFrame` Custom Carousel Physics
- Custom Canvas Parallax UI

## Running Locally

To run this application on your local machine:

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Aesthetic Engine
This project utilizes a strictly defined monochrome aesthetic system with fine-tuned interactive animations, 3D physics loops, and Tailwind CSS utility-driven component architectures.
